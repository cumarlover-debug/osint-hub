# osint-hub browser extension

Right-click to search in the OSINT tools that can take it:

- **Selected text**: an email, domain, IP, hash, wallet, username…
- **A link**: searched as a URL
- **An image**: reverse image search
- **The page**: looks up the site's domain

It opens the osint-hub launcher, with the value already filled in and its type detected. Tick the tools you want
and press **Open selected**: the tabs open in the background, and pop-up blocking does not get in the way. The
toolbar button opens the same launcher as a pop-up.

## Privacy

- The value goes from the right-click menu to the launcher through session storage, never through a URL, so it
  does not end up in your history.
- The only site it contacts is `osinthub.pages.dev`, to download the tool list (cached for a day). Your values go
  only to the tools you choose to open.
- Permissions: context menu, storage, and access to `osinthub.pages.dev`.

## Install (developer mode, until it is in the stores)

**Chrome, Edge, Brave**

1. Download or clone this repository.
2. Open `chrome://extensions` and turn on **Developer mode** (top right).
3. Click **Load unpacked** and choose the `extension` folder.

**Firefox** (121 or newer)

1. Open `about:debugging#/runtime/this-firefox`.
2. Click **Load Temporary Add-on** and choose `extension/manifest.json`. (Temporary add-ons are removed when
   Firefox restarts.)

## Development

`lib/launcher.mjs` is a copy of `shared/launcher.mjs`, because an extension cannot load files from outside its own
folder. After changing the shared file, run `npm run extension:sync`; `npm run validate` fails if the copies differ.
Icons are generated by `scripts/extension-icons.mjs`.
